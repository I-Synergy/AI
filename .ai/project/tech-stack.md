## Package Management

- **Version Control:** Central Package Management. `Directory.Packages.props` sets `ManagePackageVersionsCentrally` and holds every version. Project files reference packages without a `Version`.
- **NuGet audit:** A build gate. `NuGetAuditMode` is `all`, `NuGetAuditLevel` is `low`, and NU1900 to NU1905 are errors, so an audit that never ran cannot pass.
- **Package Source:** nuget.org only. `nuget.config` clears the inherited sources and maps every package to nuget.org. [CUSTOMIZE: private feed]
- **Version Strategy:** Pinned. The scaffold pins every version and records any pre-release pin below.

### Pre-release pins

Policy: a preview version is pinned only when no stable version existed when the versions were pinned. Each pin is listed here so it can be removed when a stable release ships.

| Package | Pinned version | Reason |
|---------|----------------|--------|
| `Aspire.Hosting.Maui` | 17.0.0-preview.1.26567.5 | No stable release of the MAUI hosting package. |

`global.json` sets `allowPrerelease: true` so the SDK resolves these pins. Remove it when no pre-release pin remains.
